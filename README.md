# My First Git Repository
A clean, professional documentation for my first local development repository created as part of my software engineering journey

## Overview
This repository tracks my progress during my Software Engineering journey. It demonstrates mastering the Linux terminal interface, setting up SSH authentication with GitHub, initializing local Git repositories, tracking changes, and writing structured documentation.

## Environment & Tools
- **Operating System:** Linux (Ubuntu / Xubuntu 24.04 LTS)
- **Code Editor:** Cursor IDE
- **Version Control:** Git & GitHub (SSH Authenticated)
- **Shell / Terminal:** Bash CLI

## Getting Started
To run or inspect this project locally:
1. Clone the repository:
```bash
git clone https://github.com/Mariam-M25/git_test
```
2. Navigate into the directory:
```bash
cd git_test
```
